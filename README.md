#  Financial Loan Analysis Dashboard

##  Project Overview

Interactive **Financial Loan Analysis Dashboard** developed to monitor loan portfolio performance, credit risk, and bad-loan patterns.

##  Key Business Questions

- What is the overall loan portfolio size and bad-loan rate?
- Which loan grades have higher credit risk?
- Which states contribute the highest loan volume and value?
- Which loan purposes have the highest loan concentration?
- How are bad loans distributed across loan terms?
- Which **Grade–Purpose** combinations show higher bad-loan rates?

##  Key KPIs

- **Total Loans:** 38.6K
- **Loan Amount:** $435.8M
- **Average Loan Value:** $11.3K
- **Bad Loan Rate:** 13.8%
- **Bad Loan Value:** $65.5M
- **Bad Loans:** 5.3K

##  Key Analysis

### **Loan Performance**
Analyzed monthly loan amounts and performance across **Grades A–G**.

### **Geographic Analysis**
Compared loan volume, loan value, average loan value, and bad-loan percentage across states.

Identified **Debt Consolidation** as the largest loan-purpose category with approximately **$232.5M** in loan value. :contentReference[oaicite:1]{index=1}
